# Break İfadesi ile Döngüden Çıkış 
## Proje Hakkında
Bu proje, Nesne Tabanlı Programlama dersi kapsamında Python kullanılarak hazırlanmış temel bir döngü uygulamasıdır. Program, kullanıcıdan sürekli kelime girmesini ister ve belirlenen kelime girildiğinde döngüyü sonlandırır.

## Proje Ne Yapar?
- `while True` kullanarak sürekli çalışan bir döngü oluşturur.
- Kullanıcıdan bir kelime girmesini ister.
- Girilen kelimenin `chupacabra` olup olmadığını kontrol eder.
- Farklı bir kelime girildiğinde yeniden giriş yapılmasını sağlar.
- Doğru kelime girildiğinde `break` komutuyla döngüyü sonlandırır.
- Döngüden başarıyla çıkıldığını belirten mesajı ekrana yazdırır.

## Proje Neden Faydalıdır?
Bu çalışma, Python'da `while` döngüsünün, `break` ifadesinin ve koşullu yapıların kullanımını öğrenmek amacıyla hazırlanmıştır. Sonsuz döngülerin belirli bir koşul gerçekleştiğinde nasıl sonlandırılabileceğini gösterir.

## Proje Nasıl Çalıştırılır?
1. Bilgisayarınızda Python 3'ün yüklü olduğundan emin olun.
2. Proje dosyasını Python IDLE üzerinden açın.
3. `F5` tuşuna basarak programı çalıştırın.
4. İstenilen alana bir kelime girin.
5. `chupacabra` kelimesini girene kadar programın tekrar kelime istediğini gözlemleyin.
6. Doğru kelime girildiğinde döngünün sona erdiğini görüntüleyin.

## Örnek Kullanım

**Girdi ve Çıktı:**

```text
Enter a word: python
Enter a word: hello
Enter a word: chupacabra
You've successfully left the loop.
```
